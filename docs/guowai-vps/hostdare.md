- **面向中国大陆访客**：看洛杉矶 CSSD 或 CAMD。商城标注中国电信 CN2 GIA（AS4809）、联通 AS9929 和移动 CMIN2（AS58807）单程优化。购买前按自己的运营商测晚高峰。

## 常见问题

**$20.99/年是 CN2 GIA 吗？**  
这个活动价对应洛杉矶普通线路 ASSD0。CN2 GIA 看 CSSD 或 CAMD 系列。

**循环折扣会锁定续费价吗？**  
循环折扣描述的是优惠可用于后续账期。HostDare 已公告调整部分旧促销套餐的续费价格，具体金额以账单为准。

**低配能装 Windows 吗？**  
CSSD0 和 NKVM0 的商城页面只列 Linux。需要 Windows 时先查目标套餐支持情况和授权要求。
