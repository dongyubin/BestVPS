## 要知道的坑

**1. 非优化线路要先中转**

英国、新加坡、台湾、越南、德国这几条线是本地 BGP，不针对大陆优化。官方自己的说明就是“联通和部分地区移动直连尚可，建议用香港或日本线路中转”。拿来做大陆访问主站会很难受，拿来做落地 IP 才是正确用法。

**2. 带宽普遍不大**

除了英国、新加坡、台湾的 300Mbps，大部分套餐是 50–100Mbps，不限流量款甚至只有 20–30Mbps。它不是大带宽机器，别按“跑满千兆”的预期买。

**3. 静态住宅 VDS 只退余额**

美国加州、西雅图、北卡以及日本、德国的静态住宅 IP 产品属于“特殊产品”，退款只退到网站余额，不退现金。普通 VPS 才是 48 小时无条件退款。

**4. 部分 IP 段禁 ping**

官方说明：应 IP 提供方要求，部分住宅 IP 段禁用了 ping，ping 不通是正常的，不影响实际使用。测机时别只靠 ping 判断死活。

**5. 特价库存有限**

香港基础版等套餐标注“特价限售 20 台”，卖完就恢复原价或下架。看到合适的价格不要拖太久。

## 常见问题

### 丽萨主机的 IP 和普通 VPS 有什么区别？

普通 VPS 用的是机房 IP，容易被流媒体和电商平台判定为代理。丽萨主机分配的是宽带运营商的住宅 IP（双 ISP 家宽），在 TikTok、ChatGPT、Netflix 这类场景里识别率低得多，这是它价格比普通年付机贵的主要原因。

### 买哪个套餐最划算？

只想低成本拿一个美国住宅 IP：美国 4837 或纽约、芝加哥的年付 399 元档。需要大陆访问速度快一点：美国 9929 年付 499 元档。要香港低延迟：566 元/年的香港特价版。要 TikTok 运营的高质量 IP：日本 IIJ、香港 HGC 这类双 ISP 住宅款。

### 香港机器大陆访问快吗？

三网直连那条线（CMI/CU2/CN2）官方标注平均延迟 50ms 左右，是它家对大陆最友好的产品。HGC、iCable 是住宅 IP 产品，线路质量要单独看，别混为一谈。

### 能装 Windows 吗？

美国 9929 等国区套餐支持安装 Windows，具体以购买页说明为准。低配 1G 内存跑 Windows 会比较吃力，建议至少 2G。

### 支持退款吗？

普通 VPS 48 小时内不满意无条件退款；静态住宅 IP VDS 等特殊产品只退网站余额。下单前看清产品页的退款说明。
